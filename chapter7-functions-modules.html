7.1 — Why Functions and Modules?
As programs grow larger, code becomes harder to read and maintain. Functions and Modules break complex problems into small, manageable, reusable pieces — the foundation of professional programming.
Chapter 7Foundation
🏥 Real-Life Analogy — Hospital Organisation
A hospital has departments: Cardiology, Pediatrics, Emergency (modules). Each doctor performs specific tasks (functions). The hospital does NOT function as one giant undivided room! Python programs are organised the same way.
♻️ Code Reusability

Write once, use many times. Call a function from anywhere without rewriting code.

📖 Readability

Named functions make logic crystal clear — calculate_area() is self-explanatory.

🐛 Easier Debugging

Bugs are isolated to a specific function — not hiding in 500 lines of unstructured code.

7.3 — Imported Modules: math & statistics
A module is a Python file containing related functions. Import them before use. Python's standard library has 200+ modules — we study math and statistics.
7.32 Key Modules

Method 1 — Import Entire Module

import math import statistics result = math.sqrt(25) # use dot (.)

Method 2 — Import Specific Function

from math import sqrt from math import sqrt, ceil result = sqrt(49) # no dot needed!
⚠️ Avoid from module import *
Importing everything can cause naming conflicts. If two modules have a function with the same name, one overwrites the other. Best practice: import only what you need!

"ceil" = ceiling (above you → rounds UP). "floor" = floor (below you → rounds DOWN).

🧩 Understanding above = [m for m in marks if m > avg]Concept
import statistics marks = [20, 25, 19, 85, 56, 74, 89] avg = statistics.mean(marks) above = [m for m in marks if m > avg]
The last line is a list comprehension — a concise way to build a new list by looping through marks and applying a filter condition. It means:
"Create a new list called above, containing only the values m from marks where m is greater than the average avg."
above = [ m for m in marks if m > avg ]
Read it in three parts →
m
OUTPUT — what to collect and put into the new list each time
for m in marks
LOOP — take each value in marks, one at a time, calling it m
if m > avg
FILTER — keep m only when this condition is True
It is functionally equivalent to →
✨ List comprehension (short form)
above = [m for m in marks if m > avg]
🔁 Ordinary for-loop (long form)
above = [] for m in marks: if m > avg: above.append(m)
# Worked example — with the marks above

above = [85, 56, 74, 89] # only the four marks greater than 52.57

7.4 — User-defined Functions
Programmers create custom functions using the def keyword for specific tasks. Define once — call many times. Functions accept inputs (parameters) and return outputs (return values).
7.4def keyword

Syntax — Defining a Function

def function_name(param1, param2): # body — indented 4 spaces statement_1 statement_2 return value # optional
⚠️ Defining is NOT Executing!
A def statement only stores the function in memory. It does NOT run it. Call the function by writing its name with ().

Flow of Execution

→ Python reads all def statements → Stores them in memory (NOT run yet) → Starts at FIRST line outside defs → Hits a function CALL → jumps in → Executes function body → Returns to calling line → Continues normal execution

📥 Formal Arguments (Parameters)

Variables in the function definition. They receive the values passed by the caller.

def interest(P, N, R):

P, N, R are FORMAL parameters

📤 Actual Arguments

Values passed when calling the function. Copied into formal parameters by position.

interest(5000, 3, 8)

5000, 3, 8 are ACTUAL arguments

💡 The Mapping
When called: P ← 5000, N ← 3, R ← 8. Actual values are copied into formal parameters. Order must match!

7.6 — Scope Rules: Local & Global
The scope of a variable defines where it can be accessed. Python uses the LEGB rule: Local → Enclosing → Global → Built-in.
7.6LEGB Rule
🌍 Global Variables
  • Defined outside all functions
  • Accessible anywhere in the program
  • Can be READ inside functions freely
  • To MODIFY inside a function → need global keyword
🏠 Local Variables
  • Defined inside a function
  • Accessible only within that function
  • Created fresh when function is called
  • Destroyed when function returns

7.7 — Recursive Functions
A function that solves a problem by calling itself with a smaller version of the same problem, until it reaches a simple known answer — the base case.
7.7Self-calling
🛑 Base Case

The condition that STOPS recursion. Without it → infinite recursion → program crash! The simplest version with a known answer.

if n == 1: return 1 # STOP!
🔄 Recursive Case

The function calls itself with a smaller/simpler argument. Each call moves closer to the base case.

return n * factorial(n-1)
🌍 Real-Life Analogy — Russian Nesting Dolls
To open the biggest doll → open the next smaller one → and the next → until you reach the tiny solid doll with nothing inside (base case!). Then count them all going back up. Recursion works exactly this way!

n! = n × (n-1) × … × 1. Recursively: n! = n × (n-1)! with base case: 1! = 1

📊 Tracing factorial(5) — The Call Stack
GOING DOWN — calling: factorial(5) = 5 × factorial(4) factorial(4) = 4 × factorial(3) factorial(3) = 3 × factorial(2) factorial(2) = 2 × factorial(1) factorial(1) = 1 ← BASE CASE! STOP HERE COMING BACK UP — unwinding: factorial(1) returns 1 factorial(2) returns 2 × 1 = 2 factorial(3) returns 3 × 2 = 6 factorial(4) returns 4 × 6 = 24 factorial(5) returns 5 × 24 = 120 ← FINAL ANSWER

7.8 — Creating User-defined Modules
A user-defined module is simply a .py file containing functions. Save it once — import it in any other Python program in the same folder.
7.8.py files
🧰 Real-Life Analogy — The Toolbox
You keep all carpentry tools in one box (calculator.py), all electrical tools in another (geometry.py). When you need them, you open the right box. You don't carry all tools everywhere — just import what you need!

Step 1 — Create Module File

# File: calculator.py def add(a, b): return a + b def subtract(a, b): return a - b def multiply(a, b): return a * b def divide(a, b): if b != 0: return a / b return 'Error: Division by zero'

Step 2 — Import and Use

# File: main.py (SAME folder!) import calculator print(calculator.add(15, 10)) # 25 print(calculator.divide(20, 5)) # 4.0 # Or import specific function: from calculator import divide print(divide(20, 5)) # no prefix!
📌 Module Location Rule
For import calculator to work, calculator.py must be in the SAME FOLDER as the program that imports it. For classroom use — always keep both files in the same directory!
