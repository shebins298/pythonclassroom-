Control Statements

Decisions and repetition — the point where indentation stops being a style preference and becomes the entire mechanism for scoping a block. This is usually where a C++ class either clicks with Python or fights it.

C++ — braces mark the block
if (score >= 30) {
    cout << "Pass";
}
Python — indentation IS the block
if score >= 30:
    print("Pass")
runs instantly · fully offline
Get the indentation wrong in Python and you don't get a warning — you get an IndentationError, or worse, a program that runs and does the wrong thing silently. Worth flagging early.

6.2.4 · match – case

Pattern matching, Python 3.10+

Closest thing Python has to C++'s switch — but pattern-based rather than purely value-based, and it can carry a guard condition per case.

6.3 – 6.4 · Iteration

while (indefinite) and for (definite)

while repeats as long as a condition holds — you don't know the count in advance. for repeats a known number of times, usually over range(). Both exist in C++ too, but Python's for is fundamentally a "for-each over a sequence," not a three-part counter loop.

Problem 6.11 — count the digits in a number by repeatedly floor-dividing by 10 until it hits zero. Classic indefinite loop: you can't know the digit count in advance.

ready ✓

Problem 6.13 — range(5) generates 0, 1, 2, 3, 4. Starts at 0, stops before the number given — same off-by-one convention as a C++ for(int i=0; i<5; i++).

ready ✓

Two arguments: range(1, 11) starts at 1 and stops before 11 — that is, 1 through 10.

Problem 6.14 — the third argument is the step. Negative steps count backwards.

Problem 6.15 — a string is itself a sequence, so for walks it character by character. No index variable needed, unlike C++'s typical for(int i=0;i<s.length();i++).

The underscore placeholder

When the loop variable itself is never used, Python convention names it _: for _ in range(5): print("Hello") — signals "repeat 5 times, the counter doesn't matter" more clearly than picking an unused name like i.

6.6 · Nested loops

A loop inside a loop

The inner loop runs to completion for every single pass of the outer loop. Any combination works — for-in-for, while-in-while, or mixed.

Problem 6.22 — a multiplication table. Outer loop picks the row; inner loop fills that entire row before the outer loop advances.

Problem 6.23 — a right-angled triangle. The inner loop's range depends on the outer loop's current value — that dependency is what makes it a triangle instead of a rectangle.

ready ✓

A break inside the inner loop only exits the inner loop — the outer loop is untouched and moves to its next iteration normally.

ready ✓

Teaching tip

Notice the output has three rows (i=1,2,3), each stopping after just one printed pair — the inner break never once touches the outer loop. There's no way to break out of both loops at once in Python without a flag variable or restructuring — worth naming as a real limitation, since C++ has the same limitation with nested loops and break.

Wrap-up

Session summary

Today: the five decision-making forms (if, if…else, if…elif…else, match–case, nested if…else), the two loop types and every form of range(), the four loop-control keywords, and how nesting combines any of these into two-level repetition.

Five habits to reinforce with C++ students

  • Indentation isn't cosmetic — it's the only thing marking where a block starts and ends.
  • elif, not else if — one word, and it needs its own colon.
  • range(n) stops before n — same off-by-one convention as a zero-indexed C++ loop, just less visible.
  • A loop's else runs only when the loop finishes without break — genuinely new, no C++ equivalent.
  • pass is a placeholder that does nothing; it is not the same as continue, which actually skips ahead.
