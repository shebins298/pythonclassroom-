Functions and Modules

C++ makes you declare a prototype before you can even use a function. Python doesn't — a function is just a value, defined once and called wherever it's needed, with defaults and keyword arguments doing work that C++ hands off to overloading.

C++ — prototype, then definition
int interest(int P, int N,
             int R=10);
...
int si = interest(1000, 2);
Python — define once, call anywhere below it
def interest(P, N, R=10):
    return P*N*R/100

print(interest(1000, 2))
runs instantly · fully offline
No header file, no forward declaration, no function overloading — one def, optional default values, and keyword arguments cover most of what C++ needs several mechanisms for.
7.1 · Functions in Python

Built-in, imported, and user-defined

Python groups every function you'll ever call into three buckets: built-in functions that are always available (print, int, len…), imported functions that live in modules you have to import first, and user-defined functions — the ones you write yourself with def. This chapter walks through all three.

7.2 · Imported functions

Modules — functions grouped by purpose

All the related functions are grouped together into modules according to their purpose. Some common modules are math, statistics, string, and random. A module has to be imported before its functions can be used — unlike built-ins, which are always available.

Syntax: import <module name1, module name2, ...>. Access a function inside the module using the dot operator: math.sqrt().

ready ✓

A module can be imported and given a shorter name using the as keyword — handy when a module name is long or you're importing several.

ready ✓

Syntax: from <module> import <function1, function2, ...>. Once imported this way, the function is called directly — no module prefix needed. from math import * imports everything the module offers.

ready ✓
math module

Provides access to many mathematical functions

Teaching tip

math.pow() always returns a float, even when both arguments are whole numbers — unlike the ** operator, which returns an int for two int operands. Worth a side-by-side: math.pow(4,3) gives 64.0, but 4**3 gives 64.

7.3 · User-defined functions

Written for your own specific task

A user-defined function is written to perform a specific task according to the programmer's requirements. Define it once with def, then call it by name as many times as needed.

Syntax:

def function_name(argument_list):
    function statement1
    function statement2
ready ✓

A return statement sends a value back to the caller, exactly like a C++ function whose return type isn't void.

ready ✓

Python functions can return more than one value at once — separate them with commas and Python packs them into a tuple. Unpack them the same way on the calling side. C++ needs pointers, references, or a struct to do this; Python just needs a comma.

ready ✓

Teaching tip

Run the "Defining a function" tab and point out: line() and welcome() are defined before they're called — same requirement as C++ if there's no prototype. But there's no separate declaration step; the def block both declares and defines in one motion.

7.4 · Types of arguments

Four ways to pass values into a function

Positional, default, keyword, and variable-length — Python supports all four, and a single function definition can mix several of them.

Arguments passed in the correct order, matching the function's argument list exactly.

ready ✓

Some arguments can be given a default value in the function definition — used only when the caller doesn't supply that argument. A default argument must be the rightmost one in the argument list.

ready ✓

Arguments passed by explicitly naming each formal argument along with its value. The order they're given in doesn't matter — something C++ has no equivalent for.

ready ✓

Allows a function to accept any number of arguments — prefix an argument with * in the function definition, and it collects every extra positional argument into a single sequence.

ready ✓

Teaching tip

Try calling the default-argument demo with three positional values instead of two — interest(1000, 2, 15) — and watch R take 15 instead of its default. Defaults only kick in when an argument is omitted, not as a fallback for any particular value.

7.5 · Scope rules

Where a name lives, and who can see it

A variable created inside a function belongs to that function's local scope and disappears once the function returns. A variable created at the top level of the program belongs to global scope and is visible everywhere — including inside functions, for reading.

A name assigned inside a function exists only for the duration of that call. Trying to read it from outside raises a NameError — exactly the same lifetime rule as a variable declared inside a C++ function body.

ready ✓

A name assigned at the top level is visible for reading inside any function, without needing to be passed in as a parameter.

ready ✓

Assigning to a name inside a function — even one that already exists globally — creates a brand-new local variable that shadows the global one for the rest of that function call. The global variable outside is left untouched.

ready ✓

To actually modify a global variable from inside a function (rather than shadow it), declare it with the global keyword first.

ready ✓

Teaching tip

Run "Overriding" and "global keyword" back to back with the outputs on screen together. Same-looking code, opposite effect on the outer x — the only difference is one line, global x. That contrast is the whole lesson.

7.6 · Recursive functions

A function that calls itself

Every recursive function needs two parts: a base case — the condition that stops the recursion — and a recursive part, where the function calls itself with arguments that move closer to the base case.

factorial(5) calls factorial(4), which calls factorial(3), and so on down to the base case at factorial(1) — then every pending call multiplies its way back up: 1 → 2 → 6 → 24 → 120.

ready ✓
factorial(5)5! = 5 × factorial(4)→ 120
factorial(4)4! = 4 × factorial(3)→ 24
factorial(3)3! = 3 × factorial(2)→ 6
factorial(2)2! = 2 × factorial(1)→ 2
factorial(1)base case→ 1

Peels off one digit at a time using % 10, and recurses on the rest of the number using // 10, until nothing is left.

ready ✓

Two base cases (n==0 and n==1) and a recursive part that branches into two further calls rather than one — this is why naive recursive Fibonacci gets slow fast for larger n.

ready ✓

Teaching tip

C++ students already know recursion from that language — the concept transfers directly. What's worth calling out is the missing base case: try deleting the if n==0: return 1 line from the factorial demo and running it. It'll fail with a RecursionError once it hits the simulator's safety limit — the exact failure mode of infinite recursion, just caught before it can lock up the browser.

7.7 · User-defined modules

A module is just a .py file

A user-defined module is a Python file with a .py extension that contains definitions of functions, variables, or classes. Any other program can import it and use everything it defines.

calculator.py — reference only, not runnable here 
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    return a / b
calc_add.py — in the same folder as calculator.py 
import calculator

a = 20
b = 5
print("Addition: ", calculator.add(a, b))

Why this one isn't a live demo

This page runs entirely in one browser tab with no file system — so it can't actually save calculator.py and import it from a second file the way a real IDLE session on a lab machine can. Do this one live on your own machine instead: save the two files above side by side and run calc_add.py.

Wrap-up

Session summary

Today: the three kinds of functions (built-in, imported, user-defined), the type-conversion and utility built-ins, importing whole modules vs. selected functions, the math and statistics modules, defining your own functions with def/return, all four argument styles, local vs. global scope and the global keyword, and recursion with a base case and a recursive part.

Five habits to reinforce with C++ students

  • No prototypes, no headers — a def block is the declaration and the definition.
  • Assigning to a name inside a function makes it local by default — reading an outer variable works without any keyword, but writing to it needs global.
  • Multiple return values aren't a special feature — it's just a comma-separated return, packed into a tuple.
  • Keyword arguments (f(y=2, x=1)) have no C++ equivalent — argument order stops mattering once you name them.
  • A module is nothing exotic — it's just a .py file, imported the same way as math or statistics.
