4.0 · Why a new language at all

From machine code to Python, in one breath

Your students already know why we need high-level languages — C++ made that case. Python makes the same case again, one step further toward plain English.

⚙️

C++: compile, then run

A C++ compiler translates the entire program into machine code up front, producing an executable. Errors surface at compile time, before anything runs.

🔄

Python: interpret, line by line

The Python interpreter converts source code to bytecode — a platform-independent intermediate form — and executes it line by line. A syntax error later in the file won't stop earlier lines from running first.

Teaching tip

This is usually the first "aha" for a C++ class: ask them to predict what happens if line 5 of a 10-line script has an error. In C++, nothing runs. In Python, lines 1–4 execute, output appears, then it crashes on line 5. Demo it live using the Script tab below.

Worth mentioning in class

Python was created by Guido van Rossum, a Dutch programmer, who began working on it in the late 1980s. The first official release, Python 0.9.0, came out in 1991. He named the language after the British comedy show Monty Python's Flying Circus — not the snake — because he wanted something short, memorable, and a little quirky.

4.1 · Introduction to Python

What makes Python worth the switch

Frame each of these against what a C++ student already struggles with — that's the fastest way to make the value land.

📖

Reads like English

Simple syntax means students focus on logic, not on hunting for a missing semicolon or brace.

📦

Libraries & frameworks

Libraries are reusable functions/classes for a task (math, graphics, networking). Frameworks give a full structure to build on — Django and Flask for the web; Pandas, TensorFlow and Scikit-learn for AI/ML and data science.

🌍

Cross-platform

The same code runs on Windows, Mac and Linux with little to no change — similar promise to C++, delivered with far less setup friction.

🔓

Open source & free

Source is freely available to use, modify and distribute, improved continuously by a large global community.

Teaching tip

Have students count lines: the same task (say, swapping two variables, or summing a list) is often 3–5 lines in Python vs 10+ in C++. Fewer lines isn't "less real programming" — it's less ceremony around the same logic. Worth saying explicitly, since some C++-trained students read brevity as "not serious."

4.2 · Python IDEs

Meet IDLE

An IDE is a single workspace for writing, running and debugging code — think Code::Blocks or Dev-C++, but for Python. This textbook uses IDLE 3.10.12 on GNU/Linux. A Python interpreter must be installed for any IDE to actually run code.

  1. Press the Super key to open the desktop search bar.
  2. Type idle (case doesn't matter).
  3. Click the IDLE icon — this opens the IDLE Shell, showing the >>> prompt.
  4. The >>> prompt means the interpreter is idle and ready for your next instruction — hence the name "IDLE."

Teaching tip

If your lab machines are Windows, IDLE ships with the standard python.org installer instead of a desktop search. Either way, the on-screen behaviour once it's open — the >>> prompt — is identical to what's shown here, so the rest of this session applies unchanged. Thonny and VS Code are common alternatives if a lab already has them installed.

Wrap-up

Session summary

Today: what an interpreter and bytecode are, why Python's syntax is lighter than C++'s, how to open IDLE, and the two modes of running code — interactive and script.

Five habits to reinforce with C++ students

  • No semicolons, no braces — indentation is not a style choice, it's syntax.
  • print() replaces cout << — and it's a function, so arguments go in parentheses.
  • No int main() — a script just executes top to bottom.
  • Variables aren't declared with a type — Python infers it, and it can change.
  • The Shell (>>>) is for quick experiments; real programs belong in a saved .py script.
